# Changelog

All notable changes to the `lorentzian-classification` alias crate are
documented here. Functional changes happen in
[`lorentzian-classification-core`](https://crates.io/crates/lorentzian-classification-core);
see its changelog for algorithm and API history.

## 0.1.0

Initial crates.io release.

- Re-exports the full public surface of `lorentzian-classification-core 0.1`.
- `csv` cargo feature (default) forwarding to the core crate's `csv` feature.
